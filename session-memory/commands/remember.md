---
description: 把要点存入会话记忆（默认项目记忆；写明"全局"则存全局记忆）
---

把下面的要点存入会话记忆：

$ARGUMENTS

要求：

1. 若上面的要点为空，先问用户要记什么，不要编造内容。
2. 目标文件：要点中明确写"全局"时用 `~/.zcode/memory/GLOBAL.md`，否则用当前工作区的 `.zcode/memory.md`。
3. 先 Read 目标文件（不存在则新建，项目记忆首行 `# 项目记忆`，全局记忆首行 `# 全局记忆`），再把要点并入合适分类，格式 `- [YYYY-MM-DD] 分类: 内容`（分类用 决定/偏好/约定/进度/坑，日期用今天的日期）；有相似旧条目就改写，不要重复堆叠。
4. 要点里含密钥/token/密码/私密地址时拒绝写入，并向用户说明原因。
5. 完成后一句话汇报：写入了哪个文件、新增或改写了哪条。
